# Sunpetal Valley — Asset Import & Polish Checklist

Use this checklist on every imported model before placing it in the game.

## 1. Basic Import
- [ ] Model file imported successfully
- [ ] Correct orientation
- [ ] Correct scale
- [ ] Pivot/origin reasonable
- [ ] No missing meshes

## 2. Material Review
- [ ] Materials assigned correctly
- [ ] No broken texture links
- [ ] Roughness/metalness checked
- [ ] Colors adjusted to Sunpetal palette
- [ ] Surface no longer looks flat/clay-like

## 3. Technical Quality
- [ ] Normals/shading look correct
- [ ] Polycount reasonable for web/mobile
- [ ] Transparent materials used carefully
- [ ] No excessive draw-call complexity if avoidable

## 4. Style Fit
- [ ] Fits underwater fantasy tone
- [ ] Feels compatible with Winx × Bratz × Monster High × Y2K direction
- [ ] Recolored/stylized if needed
- [ ] Does not look obviously from a different game style

## 5. Placement
- [ ] Placed with logical composition
- [ ] Does not block pathing
- [ ] Helps foreground / midground / background layering
- [ ] Enhances focal points or dead space meaningfully

## 6. Gameplay Check
- [ ] Interactions still readable
- [ ] Crop areas remain clear
- [ ] Navigation still clear
- [ ] Works from gameplay camera distance

Only keep the asset if it passes most of the above.
